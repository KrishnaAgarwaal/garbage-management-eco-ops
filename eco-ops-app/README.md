# EcoOps Frontend 📱

This directory contains the mobile-first React frontend application built with Vite and Bootstrap.

For complete project documentation, system architecture, and detailed setup instructions (for both frontend and AI backend), please refer to the main [Root README.md](../README.md).

## Quick Start (Frontend Only)

Ensure you have [Node.js](https://nodejs.org/) installed, then run:

```bash
# Install dependencies
npm install

# Run in development mode
npm run dev
```

Open `http://localhost:5173` in your browser. For the best user experience, toggle your browser's dev tools to **Mobile View** (e.g., iPhone size).
